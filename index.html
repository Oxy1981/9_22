1. Теорія

Конструктор таблиці

Перед внесенням даних визначте структуру таблиці: її назву та перелік полів (стовпців) із типами. Конструктор відкривається так: Таблиці → Створити або Створити → Таблиця.

Правила іменування. Назви таблиць і полів мають бути зрозумілими, короткими й не повторюватися в межах таблиці. Уникайте спецсимволів і зайвих пробілів — замінюйте їх на «_», наприклад Nazva_pozytsii або Ціна_грн.

Первинний ключ і автоінкремент

Первинний ключ (PRIMARY KEY) — поле (або комбінація полів), що однозначно ідентифікує кожен запис. Його значення ніколи не повторюються і не бувають порожніми. У конструкторі ключ позначають прапорцем у стовпці зі значком золотого ключа.

Автоінкремент (autoInc) — режим для ключа типу «Ціле число» (зазвичай поле ID). Поставивши прапорець ключа, ви побачите запит: «Встановити його тип як ціле число з автоінкрементом?».

  • Відповідь «Так» — база сама нумерує нові рядки: 1, 2, 3…
  • Клітинка такого поля заблокована для ручного редагування — це захищає від помилок і дублікатів.

2. Тренажер 0 / 2

Для кожного поля за прикладом даних оберіть найкращий тип. Максимум — 2 бали (по 0,25 за кожну відповідь).

3. Тестові завдання 0 / 6

Шість завдань різного типу й складності, по 1 балу кожне. Часткова правильність дає частину бала.

Результат

0 / 8

Тренажер — до 2 балів, тести — до 6 балів. Разом — до 8 балів.

4. Практична робота (в dat.A)

Створіть структуру таблиці «Меню»: використайте різні типи полів, задайте первинний ключ ID з автоінкрементом і дотримуйтеся правил іменування. Результат покажіть учителеві.
